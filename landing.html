01 — The Problem

Who is liable when the agent orders wrong?

AI agents purchase on behalf of humans. But who is liable when the agent orders wrong? Who checks the budget? Who stops a manipulated order? Today there is no standard for this.

⚖

Unclear Liability

No protocol defines who is responsible when an agent makes erroneous transactions.

🔒

No Budget Guard

Agents can act beyond the authorized budget — no on-chain check possible.

🎭

Prompt Injection Risk

A manipulated merchant can lure the agent into unauthorized purchases.

Payment Rail

A signed mandate defines exactly what the agent may do: which merchant, which category, which budget, how many orders, which time window. Before every charge, a verifier checks automatically — no transaction without valid authorization.

Liability Model
Situation Decision Liability
Mandate signature invalid REJECT None (never charge)
Agent not authorized / Attestation invalid / Replay REJECT Agent operator
Order outside constraints (budget, merchant, category) REJECT Agent operator
Order within constraints APPROVE Principal (normal purchase)

04 — Security

9 attack vectors tested.

🔑

Ed25519 Signatures

Principal, agent and merchant sign cryptographically. Forgery computationally impossible.

🛡

Instruction Introspection

On-chain CPI attacks blocked. The verifier checks the signature directly in the Ed25519 precompile.

♻

Replay Protection

Attestation hash prevents replay of intercepted transactions.

🔒

Prompt as Hash

No plaintext on chain or at the merchant. Only a SHA-256 hash as evidence.

💸

Budget Tracking

Cumulative budget across multiple orders. On-chain state, tamper-proof.

⏱

Time Window Enforcement

Mandates expire. No transaction possible outside the signed time window.

05 — Privacy

Why not send the prompt?

✗ Naive Approach

The prompt contains personal intentions, preferences and context. Sending it to the merchant or the blockchain would be a privacy disaster — personal data, purchase behavior and intentions would be permanently publicly accessible.

"Buy me coffee, I prefer roast X,
max budget €30, I drink it daily..."
✓ Agent Mandate Approach

Only a SHA-256 hash of the prompt is transmitted — as cryptographic evidence for disputes. The verifier checks constraints, not intentions. Privacy by design.
